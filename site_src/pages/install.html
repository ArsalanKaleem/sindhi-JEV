Install

The tool needs Python 3.10 or newer and about 100 MB of disk. No GPU, no PyTorch.

1. Install the package

From a clone of the repository:

git clone https://github.com/ArsalanKaleem/sindhi-JEV.git
cd sindhi-JEV
pip install -e .

This installs the sindhijev command and its dependencies: onnxruntime, numpy, opencv-python-headless, uharfbuzz and freetype-py.

PyPIWhen the package is published, this becomes pip install sindhijev.

2. The model file

Nothing to do: on first use the tool downloads sindhijev_v2.onnx (about 30 MB) from the project's GitHub release into ~/.cache/sindhijev and checks its SHA-256. The calibration (temperature and letter threshold) ships inside the package.

To use a local copy instead (offline machines, or your own export), point the tool at it:

PowerShell$env:SINDHIJEV_WEIGHTS = "C:\path\to\sindhijev_v2.onnx"
bashexport SINDHIJEV_WEIGHTS=/path/to/sindhijev_v2.onnx

To build the file yourself from the training checkpoint:

python scripts/calibrate.py --run main_v2
python scripts/export_onnx.py --ckpt runs/main_v2/last.pt --out dist/sindhijev_v2.onnx

The export checks the ONNX outputs against PyTorch and stops if they differ by more than 1e-3. The released model differs by less than 2e-5.

3. Check the install

sindhijev --help

Optional: Tesseract

sindhijev pick --tesseract runs your installed Tesseract models (snd, urd, ara, fas) on the crop and ranks their outputs. Install Tesseract with the Sindhi language data, and put it on PATH or pass its path: --tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe".
