Reproduce

The repository holds every script, config, result file and decision. Training needs one GPU; all evaluation runs on CPU.

Set up

git clone https://github.com/ArsalanKaleem/sindhi-JEV.git
cd sindhi-JEV
python -m venv .venv
.venv\Scripts\activate          # Windows; use source .venv/bin/activate elsewhere
pip install -r requirements.lock.txt
pytest -q

Synthetic data

python scripts/prepare_text.py --corpus sd_wiki.txt     # Sindhi Wikipedia spans, sentence-hash splits
python scripts/build_lexicon.py                         # train-split word list for real-word swaps
python scripts/build_pairs.py --config configs/data_v3.json --sets val val_hard val_font_hard test_iid test_font test_hard test_font_hard

sd_wiki.txt is a plain-text dump of Sindhi Wikipedia (CC BY-SA); see docs/DATA_LICENSES.md. prepare_text.py uses the author's Sindhi normaliser sindhinorm 0.1.0 (pinned in the lock file).

Train

Training runs on Kaggle (one T4) with kaggle/train.ipynb and the bundle from python kaggle/make_bundle.py; locally:

python scripts/train.py --config configs/model_v2.json --out runs/main_v2

Ablations: configs/ablations_v1.json with kaggle/ablations.ipynb.

Evaluate

python scripts/evaluate.py --ckpt runs/main_v2/last.pt --name main_v2      # synthetic sets
python scripts/ablation_table.py                                           # ablations vs reference
python scripts/jev/eval_jev.py --results runs/jev                          # Jev zero-shot (synthetic)
The real test setscripts/real/eval_real.py refuses to run without --final and refuses if any frozen file changed. It was run once per set for the reported results; the access log is docs/real_set_access_log.md.
