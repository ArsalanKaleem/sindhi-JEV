FAQ

Is this an OCR engine?

No. It checks text that an OCR engine (or a person) produced. Use Tesseract, EasyOCR or any other engine to get the text, then check it.

Why "Jev"?

The project started from OpenBMB's MiniCPM-OCR Jev, a 2-billion-parameter model that scores OCR output against the image. Sindhi-Jev applies the same render-and-compare idea at 7 M parameters, for Sindhi dots, with a score for every letter. It is an independent project, not affiliated with OpenBMB.

Do I need a GPU?

No. The tool runs the ONNX model on CPU in about 20 ms per word crop.

Is my image uploaded anywhere?

Not by the package or the local playground: both run on your computer. If you use an online copy of the playground, the image goes to the server that hosts it.

Does it work for Urdu, Arabic or Persian?

Untested. The model was trained on Sindhi text and Sindhi dot confusions only.

What is the licence?

Code and model: Apache-2.0. The bundled Noto Naskh Arabic font: SIL Open Font License. The real test images are not redistributed where the source does not allow it; see docs/DATA_LICENSES.md.
